# 自动微分原理与计算图

自动微分是一种针对具体数值计算过程自动计算导数的方法，它通过将复杂计算分解为基本操作并构建计算图，利用链式法则递归累积局部梯度，从而在保持机器精度的同时实现高效求导。

## 自动微分的基本原理

<!-- @anchor-begin id="ad-principle" terms="1" note="自动微分的基本原理" -->
**自动微分**（Automatic Differentiation，AD）既不是通过有限差分来近似导数的数值微分，也不是直接操作解析表达式的符号微分；它的处理对象是一段具体的数值计算过程。其基本原理是：所有的数值计算都可以分解为一些基本操作（包含 $+ , - , \times , /$ 以及 $\exp, \log, \sin, \cos$ 等初等函数），然后在计算过程中利用链式法则来递归地累积梯度。因此，自动微分通常既具有较高的数值精度，也具有较好的计算效率，已成为深度学习框架的核心机制之一。
<!-- @anchor-end -->

## 计算图的结构与构建

<!-- @anchor-begin id="computational-graph" terms="2" note="计算图的定义与结构" -->
**计算图**（Computational Graph）是数学运算的图形化表示。在计算图中，每个非叶子节点表示一个基本操作，每个叶子节点为一个输入变量或常量。通过将复杂的复合函数分解为一系列基本操作，可以构建出描述整个计算过程的计算图。
<!-- @anchor-end -->

以神经网络中常见的复合函数 $f ( x ; w , b ) = \frac { 1 } { \exp \big ( - ( w x + b ) \big ) + 1 }$ 为例（其中 $x$ 为输入标量，$w$ 和 $b$ 分别为权重和偏置参数），可将其分解为6个基本函数 $h_i (1 \le i \le 6)$：
1. $h_1 = x \times w$
2. $h_2 = h_1 + b$
3. $h_3 = h_2 \times -1$
4. $h_4 = \exp(h_3)$
5. $h_5 = h_4 + 1$
6. $h_6 = 1 / h_5$ （即最终输出 $f$）

## 基于计算图的梯度累积机制

<!-- @anchor-begin id="gradient-accumulation" terms="3" note="基于计算图的梯度累积机制" -->
在计算图上求导时，整个复合函数关于某个参数的导数，可以通过计算图上输出节点与该参数节点之间路径上所有的**局部梯度**连乘来得到。如果函数和参数之间存在多条路径，则需要将这多条路径上的导数连乘结果再进行相加，得到最终的梯度。
<!-- @anchor-end -->

以 $\frac { \partial f ( x ; w , b ) } { \partial w }$ 为例，其计算路径上的连乘公式为：
$$
\frac { \partial f ( x ; w , b ) } { \partial w } = \frac { \partial f } { \partial h _ { 6 } } \frac { \partial h _ { 6 } } { \partial h _ { 5 } } \frac { \partial h _ { 5 } } { \partial h _ { 4 } } \frac { \partial h _ { 4 } } { \partial h _ { 3 } } \frac { \partial h _ { 3 } } { \partial h _ { 2 } } \frac { \partial h _ { 2 } } { \partial h _ { 1 } } \frac { \partial h _ { 1 } } { \partial w }
$$
每个基本函数的局部导数都十分简单，可以通过预设规则直接计算。

## 自动微分与符号微分的对比

![](images/87a2e934f296ac55e75af071906fb746603d90cb049429649cc731e794379910.jpg)（描述：流程图，展示了符号微分与自动微分在数学表达式和程序实现之间的对比关系）  
图4.4 符号微分与自动微分对比

符号微分直接操作解析表达式，目标是得到导数的显式表达式；自动微分则直接作用在数值程序上，在执行过程中记录基本操作，并以数值方式累积局部梯度。相比数值微分，自动微分不依赖有限差分近似；相比符号微分，它通常更适合复杂程序、控制流以及大规模张量计算。

## 自动微分的模式与工程实现

按照计算导数的顺序，自动微分可以分为前向模式和反向模式。前向模式按计算图中计算方向的相同方向递归计算梯度，适合输入维度小、输出维度大的情形；反向模式按相反方向递归计算，适合输入维度高、输出为标量损失的场景（如深度学习训练中的误差反向传播）。

在工程实现上，计算图按构建方式分为静态计算图和动态计算图。静态图在执行前先构建并优化整张图，利于全局优化与并行调度；动态图在运行时按实际控制流即时构建，灵活性高且便于调试。现代深度学习框架已融合两者优势，同时支持动态求导与图执行优化，使自动微分成为系统的基础能力。
