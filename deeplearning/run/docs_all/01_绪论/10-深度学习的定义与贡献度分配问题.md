# 深度学习的定义与贡献度分配问题

深度学习是一类以多层可学习表示为核心的机器学习方法，其核心挑战在于如何有效解决贡献度分配问题，从而指导模型参数的学习。

## 深度学习的定义

<!-- @anchor-begin id="deep-learning-def" terms="1" note="深度学习的核心定义与特征" -->
**深度学习**（Deep Learning）可以看作一类以多层可学习表示为核心的机器学习方法。与仅关注最终预测函数的浅层学习不同，深度学习强调通过多层非线性特征转换，自动学习从底层特征到高层抽象表示的映射。这里的“深度”通常指原始数据进行非线性特征转换的次数，或者在表示学习系统的有向图结构中，从输入节点到输出节点所经过的最长路径的长度。
<!-- @anchor-end -->

在深度学习中，信息在多层组件中逐层变换，逐步加工出更抽象的表示。这种多层结构能够指数级地增加特征的重用性与表示能力，从而替代人工设计的特征工程。

## 贡献度分配问题

<!-- @anchor-begin id="credit-assignment-problem" terms="2" note="贡献度分配问题的定义与直观类比" -->
随着模型层数和复杂度的增加，深度学习面临一个核心挑战：**贡献度分配问题**（Credit Assignment Problem, CAP）。该问题旨在判断系统中不同组件（component）或其参数对最终输出结果的贡献大小。
<!-- @anchor-end -->

直观来看，这类似于下围棋时的复盘：当一盘棋结束时，结果非赢即输，我们需要思考究竟是哪几步棋导致了最终的胜利或败局。在深度神经网络中，最终输出误差是由多层网络中的众多参数共同作用产生的，如何将这些误差信号有效地“归因”并分配到中间各层的每一个参数上，就是贡献度分配问题。

这一问题直接关系到模型参数应如何学习，是深度学习中的核心问题。如果无法合理分配贡献度，模型就无法知道应该调整哪些参数以及调整的方向和幅度，从而导致学习过程失效。

## 解决途径

在深度学习中，解决贡献度分配问题最成功的一类模型是人工神经网络。神经网络结合误差反向传播（Back Propagation）算法，能够利用微积分中的链式法则，将输出层的误差信号逐层向后传递，从而高效地计算出每一层参数对最终误差的贡献梯度。这使得多层模型的端到端训练成为可能，也是深度学习能够迅速发展并广泛应用的重要基础。
