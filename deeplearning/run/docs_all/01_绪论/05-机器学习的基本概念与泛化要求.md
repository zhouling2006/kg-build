# 机器学习的基本概念与泛化要求

机器学习是从有限观测数据中学习一般性规律，并对未知数据进行预测的方法，其核心在于通过训练与推断两阶段实现模型的泛化能力。作为人工智能的重要分支，机器学习逐渐成为推动人工智能从规则驱动走向数据驱动的关键因素。

## 核心机制：训练与推断

<!-- @anchor-begin id="ml-training-inference" terms="1|2|3" note="定义机器学习及其训练与推断两个核心阶段" -->
**机器学习**（Machine Learning, ML）的本质是让计算机从数据（经验）中自动分析并获得规律。从一个具体系统来看，机器学习通常包含两个核心阶段：
1. **训练**（Training）阶段：利用已有的观测数据调整模型参数，使模型能够捕捉数据中的内在规律。
2. **推断**（Inference）阶段：把训练阶段学到的规律应用到新的、未见过的样本上，从而输出预测结果。
<!-- @anchor-end -->

例如，在疾病诊断中，系统可以从历史病例（训练数据）中学习症状与疾病之间的关系，并据此判断新病人（推断数据）的病情。

## 核心要求：泛化能力

<!-- @anchor-begin id="generalization-requirement" terms="4" note="阐述泛化的定义及其在机器学习中的核心地位" -->
训练与推断之间的核心要求是**泛化**（Generalization）。模型不能只是死记硬背住训练样本（即避免过拟合），而应在未见过的数据上仍然保持稳定表现。因此，机器学习不仅要关心模型在训练集上的训练误差，更要通过验证集、测试集等方式严格评估模型在未知数据上的表现。
<!-- @anchor-end -->

泛化能力是衡量机器学习系统是否真正“学到规律”的唯一标准。如果模型在训练集上表现完美，但在测试集上表现糟糕，说明模型仅仅记住了噪声或特定样本的表象，而没有掌握一般性规律。

## 实际应用中的评估考量

在医疗、金融、自动驾驶等风险较高的实际场景中，对泛化能力的评估需要更加严谨。除了基本的预测准确率，还需要进一步关注以下维度：
- **置信度可靠性**：模型对其预测结果的把握程度是否真实反映了其出错概率。
- **错误代价控制**：在不同类型的错误（如漏诊与误诊）代价不对称时，模型能否做出最优权衡。
- **分布外稳定性**：当现实世界的数据分布发生变化（如季节更替导致疾病谱变化）时，模型是否依然稳定。
