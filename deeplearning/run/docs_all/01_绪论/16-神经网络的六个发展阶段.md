# 神经网络的六个发展阶段

人工神经网络的发展并非一条线性上升的道路，而是经历了“模型提出—遭遇质疑—因学习算法复兴—在深度学习中崛起—在大模型时代走向统一与系统化”的曲折过程。其背后的关键转折，主要来自三个因素：模型结构是否足够有表达力、学习算法是否可行以及计算与数据条件是否成熟。整体可划分为以下六个阶段。

## 第一阶段：模型萌芽（1943年~1969年）
<!-- @anchor-begin id="stage-1-genesis" terms="1" note="定义模型萌芽阶段的核心贡献" -->
这一阶段的核心问题是能否用一个可计算的模型来抽象神经元及其连接。1943年，McCulloch和Pitts提出了基于简单逻辑运算的MP模型，开启了人工神经网络研究。1958年，Rosenblatt提出了感知器（Perceptron）及其学习算法，使神经网络第一次具备了从数据中学习的雏形。这一时期的意义在于初步确立了神经网络的数学形态，但尚未解决“多层网络如何有效学习”的关键问题。
<!-- @anchor-end -->

## 第二阶段：第一次低谷（1969年~1983年）
1969年，Minsky在《感知器》一书中指出单层感知器无法表示异或等简单非线性函数，加之当时的计算机难以支撑更大规模网络训练，导致研究明显降温。不过，这一阶段在暗中酝酿复兴：1974年Werbos提出了反向传播算法（BP），1980年福岛邦彦提出了带卷积和子采样操作的新知机，为后续突破奠定了方法与结构基础。

## 第三阶段：反向传播复兴（1983年~1995年）
<!-- @anchor-begin id="stage-3-bp-revival" terms="2" note="定义反向传播复兴阶段的核心转折" -->
这一阶段的关键转折是神经网络从“受生物启发的模型”走向“可训练的机器学习模型”。反向传播算法在多层网络中的成功应用引发了研究高潮，分布式并行处理（PDP）模型使“分布式表示与连接存储知识”成为核心观点。LeCun等人将反向传播引入卷积神经网络并在手写体识别上取得成功。这表明一旦学习算法有效，神经网络就能成为强有力的机器学习模型，但研究者也开始意识到深层结构会遭遇梯度消失问题。
<!-- @anchor-end -->

## 第四阶段：统计学习占优（1995年~2006年）
这一时期，神经网络在机器学习中的主导地位被削弱。一方面，网络规模增大导致计算开销迅速上升；另一方面，当时的数据规模、硬件能力和训练技巧不足以支撑深层模型稳定训练。相比之下，以支持向量机（SVM）为代表的方法具有更清晰的理论基础，在中小规模数据上表现可靠，从而占据了主导地位。

## 第五阶段：深度学习崛起（2006年~2015年）
神经网络重新成为主流的关键在于研究者逐步掌握了训练深层网络的方法。Hinton等人通过“逐层无监督预训练+监督微调”的策略有效缓解了深层网络难训练的问题。更重要的是，训练条件发生了系统性变化：GPU提升了算力，互联网推动了数据规模增长，自动微分技术降低了构建复杂网络的门槛。随着深度神经网络在语音识别和图像分类上的突破，端到端训练逐渐替代了早期的逐层预训练。

## 第六阶段：基础模型与大模型阶段（2018年至今）
<!-- @anchor-begin id="stage-6-foundation" terms="3" note="定义基础模型阶段的三大趋势" -->
2018年后，神经网络从“面向单一任务的模型”转向“面向多任务迁移与系统集成的基础能力载体”。这一阶段体现出三个显著趋势：第一，结构逐渐统一，以Transformer为代表的架构成为多模态与NLP的核心；第二，训练范式发生变化，预训练、指令微调和对齐训练使模型具备更强的泛化能力；第三，模型开始系统化，神经网络与检索、工具调用、外部记忆结合，成为复杂智能体（Agent）系统的核心组件。
