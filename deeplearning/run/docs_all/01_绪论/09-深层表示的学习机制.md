# 深层表示的学习机制

学习好的高层语义表示需从底层特征经过多步非线性转换。深层结构通过引入非线性激活函数和增加特征重用性，能够指数级提升模型的表示能力，这是构建多层次特征表示的关键机制。

## 非线性转换的必要性

要学习到一种好的高层语义表示（通常为分布式表示），通常需要从底层特征开始，经过多步转换才能得到。这里的“**非线性**”至关重要。

<!-- @anchor-begin id="nonlinear-necessity" terms="1" note="解释为何必须引入非线性激活函数" -->
若每层都只做线性变换，例如 $f(\pmb{x}) = W_1 W_2 \cdots W_n \pmb{x}$，根据矩阵乘法的结合律，多层的效果等价于一次线性变换 $W\pmb{x}$（其中 $W = W_1 W_2 \cdots W_n$）。这意味着无论堆叠多少层，模型本质上仍然是一个线性模型，无法增加模型的表达能力，也无法拟合复杂的非线性映射。因此，每层之间必须引入**非线性激活函数**，才能使深层结构真正发挥作用。
<!-- @anchor-end -->

非线性激活函数（如 ReLU、Sigmoid、Tanh 等）打破了线性变换的局限，使得神经网络能够作为通用函数逼近器，学习并表达高度复杂的输入-输出映射关系。

## 深层结构与特征重用性

除了非线性，深层结构的另一个核心优势在于其能够极大地提升**特征重用性**。

<!-- @anchor-begin id="feature-reusability" terms="2" note="解释深层结构如何通过特征重用性提升表示能力" -->
在深层结构中，底层的简单特征可以通过不同的组合方式，在中间层和高层被多次复用，从而构建出极其丰富的复杂特征。这种**特征重用性**使得模型能够以指数级增加表示能力。例如，$n$ 个底层特征通过 $k$ 层非线性组合，可以表示的特征模式数量远超单层网络。因此，表示学习的关键是构建具有一定深度的多层次特征表示。
<!-- @anchor-end -->

这种从底层到高层的逐步抽象，正是深度学习（Deep Learning）名称中“深度”的由来。所谓“深度”，即指原始数据进行非线性特征转换的次数，或从输入节点到输出节点所经过的最长路径的长度。

## 与传统特征学习的对比

在传统的机器学习中，也有很多有关特征学习的方法，如主成分分析（PCA）、线性判别分析（LDA）、独立成分分析（ICA）等。然而，传统的特征学习一般是通过人为地设计一些准则，然后根据这些准则来选取有效的特征。

传统方法存在一个显著局限：特征的学习是和最终预测模型的学习分开进行的，因此学习到的特征不一定可以提升最终模型的性能。相比之下，表示学习（特别是基于深度学习的表示学习）强调通过多层模型自动学习多层次表示，并且能够与最终的预测任务进行联合优化。深度学习之所以重要，正是因为它为表示学习提供了一种特别有效、且能端到端优化的实现方式。
