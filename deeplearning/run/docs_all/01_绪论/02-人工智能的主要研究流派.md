# 人工智能的主要研究流派

人工智能的研究并未局限于单一路径，而是形成了以符号主义和连接主义为代表的两大主流流派，二者在基本假设、实现机制与优势上各有侧重，共同推动了智能系统的发展。

## 符号主义：基于规则与逻辑的显式表示

<!-- @anchor-begin id="symbolism" terms="1" note="符号主义的核心假设与特点" -->
**符号主义**（Symbolism）又称逻辑主义、心理学派或计算机学派，是指通过分析人类智能的功能，然后用计算机来实现这些功能的一类方法。该流派建立在两个基本假设之上：
1. 信息可以用符号来表示；
2. 符号可以通过显式的规则（比如逻辑运算）来操作。

符号主义认为人类的认知过程可以看作符号操作过程。其核心优势在于**强可解释性**，因为系统的每一步推理都基于明确的逻辑规则，易于人工追踪和验证。在人工智能的推理期和知识期，符号主义方法比较盛行，催生了定理证明器和专家系统等大量成果。
<!-- @anchor-end -->

## 连接主义：基于神经元网络的数据驱动

<!-- @anchor-begin id="connectionism" terms="2" note="连接主义的核心假设与特点" -->
**连接主义**（Connectionism）又称仿生学派或生理学派，是认知科学领域中的一类信息处理方法和理论。连接主义认为，人类的认知过程是由大量简单神经元构成的神经网络中的信息处理过程，而不是显式的符号运算。

因此，连接主义模型的主要结构是由大量简单的信息处理单元组成的互联网络，具有以下显著特性：
- **非线性**：能够拟合复杂的映射关系；
- **分布式**：知识分散存储在网络连接权重中；
- **并行化与局部性计算**：支持高效的大规模信息处理；
- **自适应性**：能够通过数据驱动的方式自动调整连接权重。

相比于符号主义，连接主义在**表示能力和数据驱动学习能力方面更强**，但其内部机制往往较难解释（即“黑盒”特性）。深度学习的主要模型——人工神经网络，正是连接主义思想的直接体现。
<!-- @anchor-end -->

## 融合趋势：神经符号模型

随着研究的深入，单一范式的局限性逐渐显现：符号主义难以处理感知等模糊任务，而连接主义在复杂逻辑推理和可解释性上存在短板。因此，当前越来越多的研究者开始关注如何融合符号主义和连接主义，建立**神经符号模型**（neuro-symbolic model）。

这类模型旨在结合两者优势，典型方法包括：
- 用逻辑规则约束神经网络的输出，保证推理的严密性；
- 用神经网络自动学习符号结构，降低人工构建知识库的成本；
- 在神经网络上实现可微推理，使符号操作能够融入端到端的梯度优化中。

本书后续内容将以连接主义为主线，系统介绍神经网络与深度学习模型；但在概率图模型、推理、知识表示等问题上，也会不断回到结构化知识与符号处理的视角，体现多种建模思想的不断融合。
