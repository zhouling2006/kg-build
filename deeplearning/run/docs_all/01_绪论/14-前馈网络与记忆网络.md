# 前馈网络与记忆网络

前馈网络通过单向信息传播实现简单非线性函数的多次复合，而记忆网络通过引入历史状态反馈赋予网络记忆功能，两者在图表示与计算隐喻上存在本质差异。

## 前馈网络：单向映射与函数复合

<!-- @anchor-begin id="feedforward-network" terms="1" note="前馈网络的定义与特性" -->
在前馈网络中，各个神经元按接收信息的先后分为不同的组，每一组可看作一个神经层。每一层中的神经元接收前一层神经元的输出，并输出到下一层神经元。整个网络中的信息朝一个方向传播，没有反向的信息传播，因此可以用一个**有向无环图**表示。前馈网络可以看作一个函数，通过简单非线性函数的多次复合，实现输入空间到输出空间的复杂映射。这种网络结构简单，易于实现，典型的全连接前馈神经网络和卷积神经网络均属于此类。

## 记忆网络：历史状态与程序隐喻

<!-- @anchor-begin id="memory-network" terms="2" note="记忆网络的定义与特性" -->
记忆网络（也称为反馈网络）中的神经元不但可以接收其他神经元的信息，也可以接收自己的历史信息。与前馈网络相比，记忆网络中的神经元具有记忆功能，在不同的时刻具有不同的状态。记忆神经网络中的信息传播可以是单向或双向传递，因此可用一个**有向循环图**或无向图来表示。记忆网络可以看作一个程序，具有更强的计算和记忆能力，循环神经网络是其典型代表。

## 核心对比与选型

前馈网络与记忆网络的核心区别在于信息流动的方向与时间维度的处理。前馈网络假设输入样本之间相互独立，通过分层结构将输入向量直接映射为输出向量，适合处理静态数据（如图像分类）；记忆网络则通过隐状态沿时间步传递记忆信息，能够捕捉序列数据中的时序依赖关系，适合处理自然语言、时间序列等动态数据。在实际应用中，大多数复杂网络都是复合型结构，即一个神经网络中包括多种网络结构，以结合两者的优势。
