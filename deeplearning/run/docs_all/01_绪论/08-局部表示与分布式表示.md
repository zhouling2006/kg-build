# 局部表示与分布式表示

在机器学习中，为了将离散符号或类别信息转化为模型可处理的数值形式，通常采用两种截然不同的数据表示方法：**局部表示**与**分布式表示**。前者是高维稀疏的离散符号表示，后者是低维稠密的连续向量表示。通过嵌入技术，可以实现两者之间的有效转换。

## 局部表示（Local Representation）

<!-- @anchor-begin id="local-representation" terms="1" note="定义局部表示及其优缺点" -->
**局部表示**（也称为离散表示或符号表示）通常可以表示为 one-hot 向量的形式。假设所有类别的名字构成一个词表 $\mathcal{V}$，词表大小为 $|\mathcal{V}|$，我们可以用一个 $|\mathcal{V}|$ 维的 one-hot 向量来表示每一种类别。在第 $i$ 种类别对应的 one-hot 向量中，第 $i$ 维的值为 1，其他维度都为 0。
<!-- @anchor-end -->

**优点**：
1. 这种离散的表示方式具有很好的解释性，有利于人工归纳和总结特征，并通过特征组合进行高效的特征工程。
2. 通过多种特征组合得到的表示向量通常是稀疏的二值向量，当用于线性模型时计算效率非常高。

**不足**：
1. **不可扩展**：one-hot 向量的维数很高，且不能扩展。如果有一种新的类别，就需要增加一维来表示。
2. **无法度量相似度**：不同类别之间的相似度都为 0（正交），即我们无法通过向量距离知道“红色”和“中国红”的相似度要高于“红色”和“黑色”的相似度。

## 分布式表示（Distributed Representation）

<!-- @anchor-begin id="distributed-representation" terms="2" note="定义分布式表示及其优势" -->
**分布式表示**（也称为分散式表示）通常可以表示为低维的稠密向量。在这种表示中，一种语义分散到语义空间中的不同基向量上。例如，用 RGB 值来表示颜色，不同颜色对应到 R、G、B 三维空间中一个点。
<!-- @anchor-end -->

和局部表示相比，分布式表示的表示能力要强很多。其向量维度一般都比较低，且很容易表示新的类别。更重要的是，分布式表示使得不同对象之间的相似度可以通过向量空间中的距离或夹角来轻松计算。

下表展示了 4 种颜色的局部表示和分布式表示示例：

| 颜色 | 局部表示 | 分布式表示 |
| :--- | :--- | :--- |
| 琥珀色 | $[1, 0, 0, 0]^\top$ | $[1.00, 0.75, 0.00]^\top$ |
| 天蓝色 | $[0, 1, 0, 0]^\top$ | $[0.00, 0.50, 1.00]^\top$ |
| 中国红 | $[0, 0, 1, 0]^\top$ | $[0.67, 0.22, 0.12]^\top$ |
| 咖啡色 | $[0, 0, 0, 1]^\top$ | $[0.44, 0.31, 0.22]^\top$ |

## 嵌入（Embedding）技术

为了结合两者的优势，我们可以使用神经网络将高维的局部表示空间 $\mathbb{R}^{|\mathcal{V}|}$ 映射到一个非常低维的分布式表示空间 $\mathbb{R}^D$（其中 $D \ll |\mathcal{V}|$）。

<!-- @anchor-begin id="embedding-def" terms="3" note="定义嵌入技术的核心机制" -->
在机器学习中，这个过程称为**嵌入**（Embedding）。嵌入通常指将高维的离散符号映射到低维的连续向量空间中，同时尽可能使语义相近的对象在向量空间中也相互靠近。
<!-- @anchor-end -->

在自然语言处理中，词的分布式表示也经常叫作词嵌入。one-hot 向量和词嵌入之间的关系，就类似于上述颜色例子中的局部表示和分布式表示。

![](images/19de298f56711058120b76f72275aee22b5755bfbb2c70446ff011530d5f63a0.jpg)
图 1.3 one-hot 向量空间与嵌入空间

如图 1.3 所示，在 one-hot 向量空间中，每个样本都位于坐标轴上；而在低维的嵌入空间中，每个样本都不在坐标轴上，样本之间可以计算相似度，从而更好地反映语义结构。
