# 大模型期的核心技术与范式

大模型期以Transformer架构和规模法则为基石，实现了人工智能从单一任务模型向具备跨任务迁移能力的通用基础模型的范式跃迁。这一阶段不仅带来了算法与算力的突破，更推动了学习方式、模型形态与系统架构的全面演进。

## 规模法则与底层架构

<!-- @anchor-begin id="scaling-law" terms="1" note="定义规模法则及其对大模型时代的推动作用" -->
**规模法则**（Scaling Law）是大模型时代的核心驱动力之一。实践表明，随着模型参数规模、训练数据规模与计算量同步扩大，模型在广泛任务上的性能往往会持续提升。后续研究进一步揭示了模型参数与训练数据之间存在最优比例关系。近年来，规模法则的概念还从训练阶段扩展到推理阶段：通过在推理时分配更多计算资源（如让模型生成更长的推理链），同样可以显著提升模型在复杂任务上的表现。
<!-- @anchor-end -->

这一时期最具影响力的技术突破是Transformer结构的提出。借助Transformer强大的并行计算与长距离依赖建模能力，研究者得以利用海量未标注数据进行自监督预训练，从而训练出能够捕捉广泛统计规律和语义结构的**大语言模型**（Large Language Model, LLM）。

## 预训练与任务适应范式

<!-- @anchor-begin id="llm-and-adaptation" terms="2|3|4" note="阐述LLM的预训练基础及上下文学习、指令微调等任务适应机制" -->
**大语言模型**（LLM）通过在海量语料上进行自监督预训练，获得了强大的通用语言理解与生成能力。在此基础上，预训练模型沿着“数据规模—模型规模—任务泛化能力”的方向持续演进，展现出极强的跨任务迁移能力。

传统机器学习依赖大量标注数据和精细的任务工程，而大模型更多依靠海量未标注数据完成预训练，再通过少量样本或自然语言提示来适应新任务，这种能力被称为**上下文学习**（in-context learning）。此外，**指令微调**（Instruction Tuning）进一步提升了模型对人类意图的理解和遵循能力。在此需要区分几个相关概念：提示（prompting）是用自然语言描述任务；上下文学习是模型在输入上下文中完成任务适配；提示学习（Prompt Learning）则常常指将提示本身设计为可学习的参数化结构。
<!-- @anchor-end -->

## 系统形态演进：从模型到智能体

随着大模型能力的不断增强，其使用方式也从“单一模型”逐渐扩展为系统级能力。一方面，模型能力从单一模态扩展到多模态，联合建模文本、图像、语音、视频等信号，推动人工智能走向“理解与生成更丰富的世界表示”。

另一方面，系统形态向**智能体**（Agent）演进。需要注意的是，模型与智能体并不完全等同：模型是核心能力载体，而**智能体**通常是由模型、工具调用、外部记忆、规划执行机制以及环境反馈共同组成的系统。这类系统能够分解复杂任务、生成计划并依序执行，使人工智能朝着更具自主性和通用性的方向前进。
