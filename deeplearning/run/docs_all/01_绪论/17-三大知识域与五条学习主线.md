# 三大知识域与五条学习主线

全书的知识体系并非单一模型的线性堆叠，而是由多个彼此联系的知识域交织而成。从知识关系的角度看，核心内容分布在三大知识域中；从阅读路径的角度看，全书可进一步概括为五条相互交织的学习主线。

## 三大知识域
<!-- @anchor-begin id="three-domains" terms="1" note="定义三大知识域及其各自侧重点" -->
全书涉及的核心知识主要分布在以下三个彼此联系的知识域中：
1. **机器学习**：为全书提供最基本的研究视角和方法语言。主要关注如何从数据中学习规律，围绕“模型、学习准则、优化算法”三个核心要素展开，是理解后续所有内容的出发点。
2. **神经网络**：本书的核心主线，也是深度学习最主要的模型载体。它本质上是一类可组合、可扩展的非线性函数族，通过多层次的信息变换逐步学习抽象表示，涵盖了前馈、记忆、注意力及图网络等多种结构。
3. **概率图模型**：提供了另一种理解机器学习的重要视角。与神经网络强调函数逼近不同，它更强调随机变量之间的依赖关系及其概率化描述，核心问题包括模型构建、概率推断与参数学习。
<!-- @anchor-end -->

这三部分内容并非并列割裂。机器学习提供统一的问题定义，神经网络是其中最重要的非线性模型，概率图模型则提供概率结构与推断机制；现代深度学习中的深度生成模型等内容，恰恰处在这些知识域的交汇处。

## 五条学习主线
<!-- @anchor-begin id="five-threads" terms="2" note="定义五条学习主线及其对应的核心问题与章节" -->
如果从阅读路径而非知识分类的角度看，全书可以概括为五条从“基础概念”逐步走向“现代系统”的路线图：
1. **机器学习基础线**：回答“什么是模型、学习准则与优化算法”，对应第2章和第3章，建立机器学习的基础语言。
2. **神经网络结构线**：回答“不同网络如何组织信息与归纳偏置”，对应第4章至第11章，系统介绍各类网络结构及优化方法，构成全书主体。
3. **概率与生成线**：回答“如何从概率建模角度理解学习与生成”，对应第14章至第16章，将视角从函数逼近扩展到概率建模。
4. **决策与交互线**：回答“智能体如何在环境中学习和行动”，对应第12章和第13章中的智能体相关内容，探讨强化学习与交互机制。
5. **现代基础模型线**：回答“为什么Transformer、大语言模型与智能体代表新的阶段”，对应第8章和第13章，聚焦当前大模型时代的新范式。
<!-- @anchor-end -->

这五条主线相互交织，帮助读者在掌握具体方法的同时，看清各类模型之间的联系以及它们在人工智能体系中的全局位置。
