# 人工智能的四个发展阶段

人工智能的发展历程并非单一直线，而是随着对“智能来自哪里”这一核心问题认知的深化，经历了推理期、知识期、学习期和大模型期四个主要阶段。这种划分并不意味着后一阶段彻底替代前一阶段，而是反映了不同时期研究者对实现智能的路径侧重。

## 推理期与知识期：规则与知识的驱动

<!-- @anchor-begin id="reasoning-knowledge-era" terms="1|2" note="推理期与知识期的核心特征" -->
**推理期**（1956年达特茅斯会议后的十几年）：早期研究者主要通过人类经验，基于逻辑或事实归纳出规则，然后编写程序让计算机完成任务（如几何定理证明器）。这一时期成果初步但研究者过于乐观，低估了实现难度，随着推理规则简单性的暴露，研究陷入低谷。

**知识期**（20世纪70年代起）：研究者意识到知识对复杂任务的重要性，催生了各种**专家系统**（Expert System）。专家系统可理解为“知识库+推理机”，必须具备三要素：领域专家级知识、模拟专家思维、达到专家级水平。这一时期主要使用 Prolog 语言进行开发，在特定专业领域取得了大量成果。

## 学习期：数据驱动的自动规律发现

对于语言理解、图像理解等人类智能行为，很难用显式的“知识”或规则来描述其背后原理。为解决这一问题，研究重点转向**学习期**，即让计算机从数据中自己学习规律。

这一阶段的核心是**机器学习**（Machine Learning），旨在设计算法让计算机从数据（经验）中自动分析并获得规律，进而对未知数据进行预测。2010年代中后期，随着数据规模和计算能力的提升，深度神经网络逐渐取代线性模型成为主流，在计算机视觉和自然语言处理等领域取得突破性进展，并为向大模型期过渡奠定了基础。

## 大模型期：规模法则与通用基础模型

<!-- @anchor-begin id="large-model-era" terms="4|5" note="大模型期的核心技术与规模法则" -->
2018年后，人工智能迈入以**大模型**（Large Model）为核心的新阶段。海量数据与高性能计算设备使得训练数十亿乃至更大参数规模的模型成为可能。实践表明，随着模型规模、数据规模与计算量同步扩大，模型性能往往会持续提升，这种经验现象被称为**规模法则**（Scaling Law）。

这一时期的关键技术突破包括：
1. **Transformer架构**：提供了强大的建模能力，支持利用海量未标注数据进行自监督预训练。
2. **大语言模型（LLM）**：如 GPT、Claude 等系列，不仅具备跨任务迁移能力，还在编程、数学推理等复杂任务上展现出专业水平。
3. **范式转换**：从依赖大量标注数据的任务学习，转向通过少量样本或自然语言提示进行**上下文学习**（in-context learning），并结合**指令微调**（Instruction Tuning）提升对人类意图的遵循能力。

大模型期的到来标志着人工智能从“实验室技术”走向“基础平台与通用能力底座”，系统形态也从静态预测走向交互式推理与行动。
