# 人工神经网络的数学模型与学习能力

人工神经网络（ANN）是由大量人工神经元互联构成的自适应非线性动态系统，通过可学习的连接权重实现复杂映射，并借助误差反向传播算法解决深度学习中的贡献度分配问题。

## 数学模型与系统本质

人工神经网络从结构、实现机理和功能上模拟人脑神经网络。在数学上，它由多个节点（人工神经元）互相连接而成。每个节点代表一种特定函数，来自其他节点的信息经过相应的权重综合计算后，输入到一个非线性激活函数中，得到新的活性值。不同节点之间的连接被赋予了不同的权重，代表一个节点对另一个节点的影响大小。从系统观点看，人工神经网络是由大量神经元通过极其丰富和完善的连接而构成的自适应非线性动态系统。

## 学习能力与通用函数逼近

<!-- @anchor-begin id="ann-universal-approximation" terms="1" note="ANN的学习能力与通用函数逼近" -->
虽然构造一个人工神经网络相对容易，但赋予其学习能力是核心挑战。早期的神经网络模型并不具备学习能力，直到误差反向传播（BP）算法被广泛应用于多层神经网络的训练，才真正解决了多层网络的学习问题。由于人工神经网络可以用作一个通用的函数逼近器（理论上，一个两层的神经网络就可以逼近任意的连续函数），我们可以将其看作一个由可学习参数控制的复杂函数。在机器学习框架下，通过梯度下降等优化方法调整神经元之间的连接权重，网络能够从数据中自动学习复杂的输入-输出映射。

## 网络容量与规模法则

<!-- @anchor-begin id="network-capacity-scaling-law" terms="2|3" note="网络容量与规模法则的定义" -->
人工神经网络塑造复杂函数的能力被称为**网络容量**（Network Capacity），这与可以被储存在网络中的信息的复杂度以及数量直接相关。理论上，只要有足够的训练数据和神经元数量，人工神经网络就可以学到很多复杂的函数。在大模型时代，人们进一步发现，随着模型参数量、训练数据量和计算量的持续增大，模型在广泛任务上的性能往往呈现出持续提升的经验现象，这被称为**规模法则**（Scaling Law）。规模法则从经验上深刻刻画了网络容量、数据和计算三者之间的内在关系，成为推动大模型时代到来的重要动力。
