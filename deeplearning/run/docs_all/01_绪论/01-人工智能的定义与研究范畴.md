# 人工智能的定义与研究范畴

人工智能（AI）的核心目标是构建能够模拟、延伸和扩展人类智能的计算系统，使其具备感知、学习、推理、决策与行动等综合能力。它并非试图逐项复制人类的所有行为，而是致力于让机器在特定任务中展现出类人的智力与能力。

## 人工智能的定义与图灵测试

<!-- @anchor-begin id="ai-definition" terms="1" note="人工智能的核心定义与图灵测试标准" -->
**人工智能**（Artificial Intelligence，AI）是计算机科学的一个重要分支，主要研究和开发用于模拟、延伸和扩展人类智能的理论、方法、技术及应用系统。1956年的达特茅斯会议标志着该学科的正式诞生，John McCarthy 将其定义为“让机器的行为看起来就像是人所表现出的智能行为一样”。

在评估机器是否具备智能时，阿兰·图灵于1950年提出了著名的**图灵测试**（Turing Test）：一个人在不接触对方的情况下，通过特殊方式与对方进行一系列问答；如果在相当长时间内，他无法根据这些问题判断对方是人还是计算机，那么就可以认为这个计算机是智能的。图灵测试促使人工智能从哲学探讨走向科学研究，并明确了机器需要具备理解语言、学习、记忆、推理和决策等能力才能通过测试。
<!-- @anchor-end -->

## 人工智能的四大研究范畴

为了实现上述目标，人工智能的研究范畴被划分为四个主要方面，涵盖了从信息输入到环境交互的完整闭环：

<!-- @anchor-begin id="ai-research-domains" terms="3|4" note="人工智能的四大研究范畴" -->
1. **感知**：模拟人的感知能力，对外部刺激信息（如视觉和语音等）进行感知和加工。主要研究领域包括计算机视觉、语音信息处理等，旨在让机器“看懂”和“听懂”世界。
2. **学习**：模拟人的学习能力，研究如何从样例或从与环境的交互中获取规律。主要研究领域包括监督学习、无监督学习和强化学习等，这是机器获取新知识、适应新环境的基础。
3. **认知**：模拟人的认知能力，涉及知识表示、自然语言理解、推理、规划与决策等。认知要求机器不仅能处理底层信号，还能理解高层语义并进行逻辑推演。
4. **行动与交互**：研究智能系统如何在环境中调用工具、执行动作、与人协作并根据反馈持续调整行为。近年来的智能体（Agent）系统就是这一方向的重要代表，强调在动态环境中的自主决策与执行。
<!-- @anchor-end -->

近年来，以大语言模型和基础模型为代表的新一代人工智能系统在这四个范畴内均取得了显著进展，不仅提升了传统感知任务的性能，也在复杂推理、内容生成和多轮交互等方面展现出强大的综合能力，深刻改变了人工智能的应用模式。
