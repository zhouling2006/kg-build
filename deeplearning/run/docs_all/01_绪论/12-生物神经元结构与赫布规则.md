# 生物神经元结构与赫布规则

生物神经元通过细胞体、树突和轴突的特定结构实现信息传递，其核心学习机制基于突触可塑性，即赫布规则。

## 生物神经元的结构

<!-- @anchor-begin id="biological-neuron-structure" terms="1" note="生物神经元的核心组成部分与功能" -->
**生物神经元**（Neuron）是人脑神经系统中携带和传输信息的基本单元。典型的神经元结构大致可分为细胞体和细胞突起两部分：
1. **细胞体**（Soma）：包含神经细胞膜，膜上的受体与神经递质结合后，会引起膜内外电位差改变，产生兴奋或抑制的生理活动。
2. **树突**（Dendrite）：从细胞体延伸出的分支，负责接收其他神经元传来的刺激并将兴奋传入细胞体。
3. **轴突**（Axon）：每个神经元通常只有一个轴突，负责将细胞体的兴奋状态传送到另一个神经元或其他组织。
<!-- @anchor-end -->

神经元之间并没有直接的物理连接，而是留有约20纳米的缝隙，通过**突触**（Synapse）这一“接口”进行互联与信息传递。当神经元接收到的信号量总和超过特定阈值时，细胞体就会兴奋并产生电脉冲，电脉冲沿轴突通过突触传递给下游神经元。

## 赫布规则与突触可塑性

从学习的角度看，人脑神经网络的关键在于神经元之间的连接如何随经验而改变。不同神经元之间的突触有强有弱，其强度可以随着刺激和经验不断变化，这种性质称为**突触可塑性**。

<!-- @anchor-begin id="hebbs-rule" terms="2" note="赫布规则的定义与学习机制" -->
1949年，加拿大心理学家 Donald Hebb 提出了突触可塑性的基本原理，后被概括为**赫布规则**（Hebb's Rule）：如果两个神经元经常共同激活，它们之间的连接会被加强。这种基于共同激活来增强连接强度的学习方式被称为赫布型学习（Hebbian learning）。
<!-- @anchor-end -->

赫布规则揭示了生物神经系统形成记忆印痕的微观机制：不同的连接模式对应不同的记忆，而连接的强度由神经元活动的协同性决定。

## 对人工神经网络的启发

生物神经元的结构与赫布规则为人工神经网络的构建提供了直接的生物学灵感。人工神经网络中的“节点”抽象自生物神经元，而节点之间的“连接权重”则抽象自突触的连接强度。赫布规则中“通过调整连接强度进行学习”的思想，直接启发了人工神经网络通过优化权重参数来拟合数据规律的学习范式，成为连接主义模型的核心基石。
