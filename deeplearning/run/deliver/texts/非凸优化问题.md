# 非凸优化问题

神经网络的参数优化通常是一个非凸优化问题。即使对于最简单的两层网络，无论是采用平方误差损失还是交叉熵损失，其损失函数关于网络参数的曲面均呈现高度非凸性，存在大量局部极小值和鞍点。这种非凸特性使得基于梯度的优化算法难以保证找到全局最优解，增加了训练的难度与不确定性。

## 非凸优化的数学表现

为了直观理解损失曲面的非凸性，可以考察一个最简单的 1-1-1 结构的两层神经网络。其输出可以表示为：

$$
\hat { y } = \sigma ( w _ { 2 } \sigma ( w _ { 1 } x ) )
$$

其中 $w _ { 1 }$ 和 $w _ { 2 }$ 为网络参数， $\sigma ( \cdot )$ 为 Logistic 函数，$\hat{y}$ 为网络输出。

假设分别使用两种常见的损失函数。第一种为平方误差损失：

$$
\mathcal { L } ( w _ { 1 } , w _ { 2 } ) = ( y - \hat { y } ) ^ { 2 }
$$

第二种为交叉熵损失：

$$
\mathcal { L } ( w _ { 1 } , w _ { 2 } ) = - \log \hat { y }
$$

## 非凸特性对训练的影响

<!-- @anchor-begin id="non-convex-impact" terms="1|2|3" note="非凸优化问题对基于梯度的优化算法的影响及核心难点" -->
在理想的凸优化问题中，任何**局部极小值**都是全局最小值，基于梯度的优化算法能够稳定收敛到全局最优解。然而，在神经网络的**非凸优化问题**中，损失曲面极其复杂，存在大量的局部极小值和**鞍点**。

这种非凸特性使得基于梯度的优化算法在训练时面临以下核心困难：
1. **陷入局部最优**：算法可能收敛到某个局部极小值，而无法保证找到全局最优解，导致模型泛化能力受限。
2. **鞍点停滞**：在高维参数空间中，鞍点比局部极小值更为普遍。在鞍点附近，梯度接近于零，导致参数更新极其缓慢，显著增加训练的难度与不确定性。
<!-- @anchor-end -->

即使对于上述最简单的两层网络，非凸性依然存在。随着网络层数和参数量的增加，损失曲面的非凸性会变得更加严重。这也是深层神经网络训练困难的核心原因之一，需要结合合理的参数初始化、自适应优化算法以及规范化技术来缓解非凸性带来的负面影响。
