# 局部表示与分布式表示

在机器学习中，数据的表示方法主要分为高维稀疏的局部表示和低维稠密的分布式表示，后者通过嵌入技术能够有效度量语义相似度并大幅提升表示能力。

## 局部表示（离散符号表示）

<!-- @anchor-begin id="local-representation" terms="1" note="局部表示的定义、优缺点" -->
**局部表示**（Local Representation）也称为离散表示或符号表示。其核心思想是以不同的独立名字或符号来命名不同的对象。在计算机中，局部表示通常可以表示为 one-hot 向量的形式。假设所有对象的名称构成一个大小为 $|\mathcal{V}|$ 的词表，我们可以用一个 $|\mathcal{V}|$ 维的 one-hot 向量来表示每一种对象，其中只有对应维度的值为 1，其他维度均为 0。

局部表示具有两个优点：
1. **解释性好**：离散的表示方式有利于人工归纳和总结特征，并通过特征组合进行高效的特征工程。
2. **计算效率高**：通过多种特征组合得到的表示向量通常是稀疏的二值向量，当用于线性模型时计算效率非常高。

但局部表示也存在两个明显的不足：
1. **不可扩展**：one-hot 向量的维数很高，且不能扩展。如果出现一种新的对象，就必须增加一维来表示。
2. **无法度量相似度**：不同对象之间的相似度均为 0（正交），即无法通过向量距离反映出“红色”和“中国红”的相似度要高于“红色”和“黑色”的相似度。

## 分布式表示（连续向量表示）

<!-- @anchor-begin id="distributed-representation" terms="2" note="分布式表示的定义与优势" -->
**分布式表示**（Distributed Representation）是指将对象的语义分散到语义空间中的不同基向量上，通常表示为低维的稠密向量。例如，用 RGB 值来表示颜色，不同颜色对应到 R、G、B 三维空间中的一个点。

和局部表示相比，分布式表示的表示能力要强很多：
1. **维度低且易扩展**：向量维度一般比较低，且很容易表示新的对象，无需像 one-hot 那样增加维度。
2. **可计算相似度**：不同对象之间的相似度可以通过向量空间中的距离或夹角很容易地计算出来，从而捕捉到对象间的内在语义关联。

## 嵌入（Embedding）技术

<!-- @anchor-begin id="embedding-tech" terms="3" note="嵌入技术的机制与空间映射" -->
在机器学习中，可以使用神经网络将高维的局部表示空间 $\mathbb{R}^{|\mathcal{V}|}$ 映射到一个非常低维的分布式表示空间 $\mathbb{R}^D$（其中 $D \ll |\mathcal{V}|$）。在这个低维空间中，每个特征不再是坐标轴上的孤立点，而是分散在整个低维空间中。这个过程称为**嵌入**（Embedding）。

嵌入通常指将高维的离散符号映射到低维的连续向量空间中，同时尽可能使语义相近的对象在向量空间中也相互靠近。例如，自然语言处理中的“词嵌入”（Word Embedding）就是将词表中的词映射为低维稠密向量。

![](../images/19de298f56711058120b76f72275aee22b5755bfbb2c70446ff011530d5f63a0.jpg)
图 1.3 one-hot 向量空间与嵌入空间

表1.1 局部表示和分布式表示示例

| 颜色 | 局部表示 | 分布式表示 |
| :--- | :--- | :--- |
| 琥珀色 | $[1, 0, 0, 0]^\top$ | $[1.00, 0.75, 0.00]^\top$ |
| 天蓝色 | $[0, 1, 0, 0]^\top$ | $[0.00, 0.50, 1.00]^\top$ |
| 中国红 | $[0, 0, 1, 0]^\top$ | $[0.67, 0.22, 0.12]^\top$ |
| 咖啡色 | $[0, 0, 0, 1]^\top$ | $[0.44, 0.31, 0.22]^\top$ |

在 one-hot 向量空间中，每个样本都位于坐标轴上；而在低维的嵌入空间中，样本不再局限于坐标轴，样本之间可以通过空间距离直接计算相似度。
