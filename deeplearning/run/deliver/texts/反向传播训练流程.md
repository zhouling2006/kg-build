# 反向传播训练流程

反向传播训练流程是利用反向传播算法结合随机梯度下降，通过“前馈计算-误差反向传播-参数更新”三步迭代来最小化正则化经验风险，从而学习前馈神经网络参数的完整工程化执行过程。

## 训练流程的三大核心步骤

<!-- @anchor-begin id="bp-training-steps" terms="1" note="概括反向传播训练流程的三大核心步骤" -->
使用误差反向传播算法的前馈神经网络训练过程可以严格划分为以下三步：
1. **前馈计算**：从输入层开始，逐层计算每一层的净输入 $\pmb{z}^{(l)}$ 和激活值 $\pmb{a}^{(l)}$，直到最后一层（输出层）。
2. **误差反向传播**：从输出层开始，利用链式法则反向递推计算每一层的**误差项** $\pmb{\delta}^{(l)}$。
3. **梯度计算与参数更新**：利用误差项计算每一层权重和偏置的偏导数，并结合学习率与正则化系数更新参数。
<!-- @anchor-end -->

### 步骤一：前馈计算
给定输入样本 $\pmb{x}$，令 $\pmb{a}^{(0)} = \pmb{x}$。对于第 $l$ 层（$l = 1, 2, \dots, L$），依次计算净输入和激活值：
$$
\pmb{z}^{(l)} = \pmb{W}^{(l)} \pmb{a}^{(l-1)} + \pmb{b}^{(l)}
$$
$$
\pmb{a}^{(l)} = f_l(\pmb{z}^{(l)})
$$
其中 $f_l(\cdot)$ 为第 $l$ 层的激活函数。此过程将输入信号逐层向前传递，最终得到网络输出 $\hat{\pmb{y}} = \pmb{a}^{(L)}$。

### 步骤二：误差反向传播
<!-- @anchor-begin id="error-term-def" terms="2" note="定义误差项及其在反向传播中的递推作用" -->
**误差项** $\pmb{\delta}^{(l)}$ 定义为损失函数 $\mathcal{L}$ 对第 $l$ 层神经元净输入 $\pmb{z}^{(l)}$ 的偏导数：
$$
\pmb{\delta}^{(l)} \triangleq \frac{\partial \mathcal{L}}{\partial \pmb{z}^{(l)}}
$$
它反映了第 $l$ 层神经元对最终损失的敏感程度。误差项满足从后向前的递推关系：
$$
\pmb{\delta}^{(l)} = f_l'(\pmb{z}^{(l)}) \odot \left( (\pmb{W}^{(l+1)})^\top \pmb{\delta}^{(l+1)} \right)
$$
其中 $\odot$ 表示 Hadamard 积（逐元素相乘）。对于输出层（第 $L$ 层），若采用交叉熵损失，误差项可直接简化为 $\pmb{\delta}^{(L)} = \hat{\pmb{y}} - \pmb{y}$，这构成了反向传播的起点。

### 步骤三：梯度计算与参数更新
<!-- @anchor-begin id="sgd-update-rule" terms="3" note="给出基于随机梯度下降的参数更新公式" -->
在计算出每一层的误差项后，损失函数关于第 $l$ 层参数的梯度可高效表示为：
$$
\frac{\partial \mathcal{L}}{\partial \pmb{W}^{(l)}} = \pmb{\delta}^{(l)} (\pmb{a}^{(l-1)})^\top
$$
$$
\frac{\partial \mathcal{L}}{\partial \pmb{b}^{(l)}} = \pmb{\delta}^{(l)}
$$
采用**随机梯度下降**时，每次利用单个样本的梯度直接更新参数。结合正则化系数 $\lambda$（仅作用于权重），参数更新规则为：
$$
\pmb{W}^{(l)} \gets \pmb{W}^{(l)} - \alpha \left( \pmb{\delta}^{(l)} (\pmb{a}^{(l-1)})^\top + \lambda \pmb{W}^{(l)} \right)
$$
$$
\pmb{b}^{(l)} \gets \pmb{b}^{(l)} - \alpha \pmb{\delta}^{(l)}
$$
其中 $\alpha$ 为学习率。

## 算法实现与伪代码

以下 C 风格伪代码完整展示了基于反向传播算法的随机梯度下降训练流程：

```c
// 输入：训练集 D，验证集 V，学习率 alpha，正则化系数 lambda，网络层数 L
// 输出：权重矩阵 W，偏置向量 b

// 1. 随机初始化参数
random_initialize(W, b);

// 2. 外层循环：直到验证集错误率不再下降
do {
    // 3. 对训练集样本随机重排序
    shuffle(D);
    
    // 4. 遍历训练集中的每一个样本 (随机梯度下降)
    for (int n = 1; n <= N; n++) {
        Sample sample = D[n];
        
        // 步骤一：前馈计算每一层的净输入 z 和激活值 a，直到最后一层
        a[0] = sample.x;
        for (int l = 1; l <= L; l++) {
            z[l] = W[l] * a[l-1] + b[l];
            a[l] = activate(z[l], l); // 应用第 l 层的激活函数
        }
        
        // 步骤二：反向传播计算每一层的误差项 delta
        // 以多分类交叉熵损失为例，输出层误差项为预测值减真实值
        delta[L] = a[L] - sample.y; 
        for (int l = L - 1; l >= 1; l--) {
            delta[l] = derivative(a[l], l) * (transpose(W[l+1]) * delta[l+1]);
        }
        
        // 步骤三：计算梯度并更新参数
        for (int l = 1; l <= L; l++) {
            // 计算当前样本的梯度 (使用矩阵/向量乘法)
            Matrix grad_W = delta[l] * transpose(a[l-1]);
            Vector grad_b = delta[l];
            
            // 结合正则化项更新权重 (注意：正则化仅作用于W，不作用于b)
            W[l] = W[l] - alpha * (grad_W + lambda * W[l]);
            b[l] = b[l] - alpha * grad_b;
        }
    }
} while (validation_error(V, W, b) is decreasing);
```

## 关键机制与易错点

1. **正则化项的差异化处理**：在参数更新时，权重衰减（正则化项 $\lambda \pmb{W}^{(l)}$）仅应用于权重矩阵 $\pmb{W}$，而**不能**应用于偏置向量 $\pmb{b}$。对偏置进行正则化不仅没有防止过拟合的实际意义，还会破坏网络对数据分布的平移不变性。
2. **输出层误差项的简化**：反向传播必须有一个明确的起点。当输出层采用 Sigmoid/Softmax 激活函数并配合交叉熵损失时，输出层的误差项 $\pmb{\delta}^{(L)}$ 会简化为极其优雅的 $\hat{\pmb{y}} - \pmb{y}$ 形式，这避免了复杂的链式求导，是工程实现中的标准做法。
3. **终止条件的设定**：训练循环的终止条件必须基于**验证集**上的错误率（或损失），而非训练集。若以训练集损失不再下降为条件，极易导致模型在训练集上过拟合，从而丧失泛化能力。
